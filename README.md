## Project Description

### Course Connection

This project aims to address one of the core concepts of the course: the development of different models to explain our solar system. The project takes on the task of illustrating the evolution from a geocentric to heliocentric model. It looks at 4 main stages. It starts with Aristotle's crystalline spheres, and is followed by Ptolemy's geocentric epicycles, Kepler's elliptical heliocentric orbits, and the modern Newtonian model. There is a timeline that shows the years these models were created and has a description of their relevance to science and popular thought. The project provides an animated visualization which highlights Aristotle's uniform circular motion, Ptolemy's deferent-and-epicycle geometry that produces retrograde loops, Kepler's equation solved numerically to generate true elliptical orbits, and Newton's gravitational mechanics governing all eight planets. The project shows that progress is non-linear and illustrates the nature of scientific progress. For example, Ptolemy's system was wrong about Earth's position, but it managed to predict planetary positions for over one thousand years. Similarly, Kepler's laws were empirical patterns that needed Newton's theoretical framework. 

### Intended Audience

We hoped this project would be available to the general public and tried to frame it as what could be an interesting exhibit at a science museum. We believe that the project is self-explanatory enough that someone with no scientific background could learn and understand the evolution of solar system models. Accordingly, we included plain language and a historical description alongside each animation. We also added features like pause, play, and adjust speed, and a key concepts section that included the most significant takeaways from each model. We put the tabs side by side to allow viewers to compare models directly rather than relying on static illustrations. We hope this made the progression from circles to ellipses and earth-centered to sun-centered more digestible.
