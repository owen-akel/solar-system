## Project Description

### Course Connection

This project directly addresses one of the central narratives of our Physics II course: the centuries-long transition from geocentric to heliocentric models of the solar system. Our interactive web application traces this evolution through four historical stages — Aristotle's crystalline spheres, Ptolemy's geocentric epicycles, Kepler's elliptical heliocentric orbits, and the modern Newtonian model. Each tab presents an animated visualization built from the actual mathematical foundations of that model: Aristotle's uniform circular motion, Ptolemy's deferent-and-epicycle geometry that produces retrograde loops, Kepler's equation solved numerically to generate true elliptical orbits, and Newton's gravitational mechanics governing all eight planets. The project demonstrates not only each model's physical claims, but also the iterative, non-linear nature of scientific progress — a theme emphasized throughout the course. Ptolemy's system was wrong about Earth's position but mathematically sophisticated enough to predict planetary positions for 1,400 years, and Kepler's laws were empirical patterns that awaited Newton's theoretical framework for explanation.

### Intended Audience

The intended audience is the general public, including anyone who has not taken a physics or astronomy course. We designed the app to be self-explanatory: each tab includes a plain-language historical description alongside the animation, controls to play, pause, and adjust speed, and a list of key concepts explaining what each model gets right and wrong. Technical terms like "epicycle," "deferent," and "eccentric anomaly" are introduced only with clear context. The side-by-side tabbed format allows viewers to compare models directly rather than relying on static illustrations, making the progression from circles to ellipses — and from Earth-centered to Sun-centered — tangible and intuitive.
